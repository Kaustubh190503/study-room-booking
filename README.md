# Study Room Booking System (ServiceNow)

## Description
A ServiceNow application to manage study room bookings with:
- Room capacity validation
- Approval workflow
- Email notifications
- Dashboard analytics

## Features
- Book rooms
- Capacity check
- Approval system
- Email alerts
- Dashboard reports

## Tech Used
- ServiceNow Studio
- Flow Designer
- Business Rules
- Client Scripts
- Reports & Dashboard

## How to Import
1. Go to ServiceNow
2. Navigate to Update Sets → Retrieved Update Sets
3. Import XML file
4. Commit Update Set
